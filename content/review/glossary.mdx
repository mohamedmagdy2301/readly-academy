كل مصطلح بمعناه البسيط ومثال من Readly.

| المصطلح | معناه | مثال من Readly |
| --- | --- | --- |
| Dependency rule | الكود الداخلي مايعرفش الخارجي، والـ imports بتشاور للداخل بس | feature_library/domain مافيهوش import لـ drift |
| Dependency inversion | الطبقة الداخلية بتعرّف الـ interface، والخارجية بتعمل implement | LibraryRepository في domain وLibraryRepositoryImpl في data |
| Entity | مفهوم business بقواعده، مش مربوط بشكل الـ API | Book |
| DTO | شكل البيانات على الشبكة أو في الـ DB بالظبط | BookDto من Open Library |
| Value object | قيمة صغيرة مضمون إنها valid من لحظة إنشائها | Email، BookId |
| Invariant | قاعدة لازم تفضل صح طول الوقت | مفيش كتاب يتضاف للمكتبة مرتين |
| Use case | عملية business واحدة بقواعدها | AddBookToLibrary |
| Composition root | المكان الوحيد اللي بيتعمل فيه توصيل الـ dependencies | apps/readly/lib/di |
| Single source of truth | مصدر واحد بس الـ UI بتقرا منه | stream من drift |
| Failure | نوع خطأ متوقع، جزء من الـ business | NetworkFailure |
| Sealed class | class أنواعها الفرعية محددة، والـ compiler يعرفها كلها | Result وFailure والـ states |
| Debounce | استنى لحد ما المستخدم يبطّل كتابة قبل ما تنفّذ | البحث بعد 350ms |
| Stale result | نتيجة رجعت متأخر بعد ما الطلب بقى قديم | بحث «flu» رجع بعد «flutter» |
| Idempotent | تكرار الطلب مايغيرش النتيجة | GET /library |
| Contract test | نفس التستات بتشتغل على كل implementation للـ interface | libraryRepositoryContract على الـ fake والـ impl |
| Barrel file | ملف بيصدّر الـ public API بتاع الـ package بس | feature_auth.dart |
| ADR | مستند قصير بيسجل قرار معماري وسببه | «ليه feature-first» |
| Flavor | نسخة من الـ app بإعدادات مختلفة | dev وstaging وprod |
| Golden test | تست بيقارن شكل الـ widget بصورة محفوظة | شاشة المكتبة بالعربي |
| Pagination | تقسيم النتايج لصفحات، وكل طلب بيجيب صفحة واحدة بس | بحث الكتالوج بيجيب 20 كتاب في الطلب |
| Infinite scroll | الصفحة الجاية بتتطلب لوحدها لما المستخدم يقرب من آخر الليست | `loadMore()` لما `extentAfter` يقل عن 500px |
| Cursor pagination | السيرفر بيرجّع اللي بعد آخر عنصر شفته بدل رقم صفحة، فالإضافة والمسح مابيزحزحوش النتايج | `after=<id آخر كتاب>` على `_id` في الـ backend بتاعك |
| PagedResult | نتيجة صفحة في الـ domain: العناصر، وهل في صفحة بعدها | `PagedResult<Book>(items:, hasMore:)` من `SearchBooks` |
| touched | علامة إن المستخدم ساب الحقل، فالخطأ يظهر بعدها مش من أول حرف | `emailTouched` في `LoginFormState` |
| account enumeration | إن رسالة الخطأ تكشف مين عنده حساب | «الإيميل أو الباسورد غلط» بدل «الإيميل ده مش متسجّل» |
| shared_preferences | package بيحفظ قيم صغيرة key-value على الجهاز، ومش متشفّر | الثيم واللغة في `SettingsStoreImpl` |
| ThemeMode.system | الثيم بيتبع إعداد الجهاز، فده اختيار تالت جنب light وdark | «زي الجهاز» في الـ SegmentedButton بتاع الإعدادات |
| Session | الفترة اللي الـ tokens فيها شغالة بعد الـ login | بتخلص لما السيرفر يرفض الـ refresh token، مش لما النت يقع |
| flutter_secure_storage | package بيحفظ key-value متشفّر: في الـ Keychain على iOS، وبمفتاح من الـ Keystore على Android | الـ access والـ refresh token في `SecureTokenStore` |
| Keychain | خزنة iOS للباسوردات والمفاتيح، وبتفضل موجودة بعد مسح الـ app | علامة first-run بتمسح الـ tokens القديمة بعد إعادة التسطيب |
| Auto-login | الـ app بيفتح على الحساب من غير باسورد لو في refresh token محفوظ | `checkSession()` في `AuthCubit`، والـ splash ظاهرة وقت `AuthUnknown` |
| Forced logout | خروج إجباري لما السيرفر يرفض الـ refresh، والمستخدم يتحوّل للـ login من أي شاشة | `onCleared` بيخلّي الـ AuthCubit يطلّع `Unauthenticated(sessionExpired: true)` |
| Breadcrumb | خطوة بتتسجل على الجهاز، ومابتتبعتش غير مع أول error | الـ `info` والـ `warning` في `SentryLogger` |
| Release | النسخة اللي الـ crash جه منها، فتعرف الـ fix وصل ولا لأ | `readly@1.4.0+42` |
| BlocObserver | class واحدة بتسمع على كل الـ Cubits في الـ app | `AppBlocObserver` بيسجّل `LibraryCubit: LibraryLoading → LibraryError` |
| Redaction | إخفاء البيانات الحساسة قبل ما تتسجل | الـ `LoggingInterceptor` بيكتب `***` مكان الـ Authorization والـ password |
| Characterization test | تست بيمسك اللي الكود بيعمله النهارده قبل الـ refactor، مش اللي المفروض يعمله | تست `NotesScreen` بـ `FakeNotesApi` |
| Feature flag | قيمة بتختار بين الكود القديم والجديد، فتقدر ترجع من غير ما ترجع كود | `AppConfig.newNotes` |
| Architecture test | تست بيقرا الـ imports وبيفرض حدود الطبقات | محدش بره الـ data يعمل import لـ dio، مع allowlist بتصغر بس |
| StreamUseCase | use case بيرجّع Stream بدل Future، للحاجة اللي بتتغير مع الوقت | `WatchLibrary` بيفلتر المكتبة بالحالة |
| StatefulShellRoute | تابات كل واحد فيها ليه Navigator، وبيفضل عايش لما تروح تاب تاني | المكتبة والكتالوج والإعدادات |
| HttpClientAdapter | الجزء في dio اللي بيبعت الطلب فعلًا، وبيتبدل بـ fake في التست | `FakeApi` في تست الـ AuthInterceptor |
| BlocSelector | بيعيد الرسم بس لما قيمة واحدة من الـ state تتغير | زرار الـ refresh في الـ AppBar بيسمع على `isRefreshing` |
| Unit test | تست لحتة logic واحدة لوحدها، من غير UI ولا شبكة، وبيخلص في milliseconds | `AddBookToLibrary` بيرفض الكتاب المتكرر |
| Widget test | تست بيرسم widget واحدة في بيئة test من غير جهاز، ويتأكد من اللي ظاهر والتفاعل | زرار «حاول تاني» بيظهر مع `NetworkFailure` |
| Integration test | تست بيشغّل الـ app كامل على جهاز أو emulator من أول شاشة | login وبعدين إضافة كتاب أوفلاين وبعدين sync |
| AAA | تقسيم التست لـ Arrange (تجهيز) وAct (تنفيذ) وAssert (تأكيد) | تجهّز `FakeLibraryRepository`، تنادي الـ use case، تعمل `expect` على الـ Result |
| Matcher | الحاجة اللي `expect` بيقارن بيها النتيجة | `isA<Err<void>>().having(...)` و`throwsA` و`emitsInOrder` |
| Test double | أي object بيقف مكان dependency حقيقية في التست: dummy أو stub أو spy أو mock أو fake | `MockSearchBooks` و`FakeLibraryRepository` |
| Stub | test double بيرجّع ردود جاهزة ومابيتأكدش من حاجة | `when(() => search(any())).thenAnswer(...)` |
| Spy | test double بيسجّل اللي اتعمل فيه عشان تتأكد منه بعدين | `FakeTokenStore.clears` بيعدّ مرات المسح |
| Test data builder | function بتعمل object للتست بقيم افتراضية، وانت بتغيّر اللي يهمك بس | `aBook(status: BookStatus.finished)` |
| Fixture | ملف بيانات ثابت بيستخدمه التست، غالبًا رد API حقيقي | `test/fixtures/search_page.json` من Open Library |
| blocTest | function من bloc_test بتختبر تسلسل الـ states اللي الـ Cubit بيطلّعها | `CatalogSearchCubit`: loading وبعدين loaded بعد الـ debounce |
| fake_async | بيخليك تقدّم الوقت في التست بإيدك بدل ما تستنى فعلًا | `async.elapse(Duration(milliseconds: 350))` للـ debounce |
| pumpAndSettle | بيرسم frames لحد ما كل الـ animations تخلص، وبيعمل timeout مع أي animation مابتخلصش | بعد الـ tap على «ضيف لمكتبتي» |
| Flaky test | تست بينجح ويفشل من غير ما الكود يتغير | تست بيعتمد على `DateTime.now` أو على ترتيب التستات |
| Regression test | تست بيتأكد إن bug اتصلّح قبل كده مارجعش | تست للـ 401 اللي كان بيعمل 3 طلبات refresh |
| TDD | تكتب التست الفاشل الأول، وبعدين أقل كود يعدّيه، وبعدين تنضّف | قاعدة الـ reading streak اتكتبت تست تست |
| Code coverage | نسبة السطور اللي اتنفّذت وقت التستات، مش نسبة اللي اتأكدنا إنه صح | 90% للـ domain والـ data كحد أدنى في الـ CI |
| Mutation testing | أداة بتغيّر الكود غلط عن قصد، وبتشوف التستات مسكت التغيير ولا لأ | تقلب `>` لـ `>=` في قاعدة، ولو التستات عدّت يبقى في حالة مش متغطية |
| Property-based testing | بدل أمثلة بإيدك، بتكتب قاعدة لازم تبقى صح لأي input، والأداة بتولّد inputs كتير | `BookDto` بعد `toJson` و`fromJson` بيرجع زي ما هو |
| Endpoint | شباك واحد في الـ API: method وpath مع بعض | `GET /library` و`POST /library` اتنين endpoints مختلفين |
| Percent-encoding | تحويل أي حرف مش مسموح في الـ URL لـ `%` ورقمين لكل byte، وبيعمله `Uri` لوحده | البحث عن «رواية» بيتبعت `q=%D8%B1%D9%88...` |
| Stack unwinding | الـ exception بتطلع من الـ function للي نادتها، وكل function في الطريق بتقف، لحد ما try يمسكها أو توصل للـ handler العام | الـ DioException بتطلع من dio للـ NotesRemoteSource للـ guard |
| Captive portal | WiFi بيرجّع صفحة login بـ HTML و200 لأي طلب لحد ما المستخدم يسجّل | `JsonOnlyInterceptor` بيحوّلها لـ `NetworkFailure(hint: captivePortal)` |
| Problem Details (RFC 9457) | شكل standard لـ error body بـ `application/problem+json`: `type` و`title` و`status` و`detail` | `"type": ".../problems/email-taken"` بدل `"code": "email_taken"` |
| Guard | الحد الوحيد اللي بيحوّل الـ exceptions لـ Failures، والمكان الوحيد للـ log | `guard(() async => ...)` في `NotesRepositoryImpl.addNote` |
| رقم المرجع (Request id) | الـ `X-Request-Id` بيتعرض للمستخدم مع أخطاء السيرفر، عشان الدعم يلاقي الطلب في الـ logs | «رقم المرجع: req_7f3a91c2» تحت رسالة الـ 500 |
| Request coalescing | لو نفس الـ GET لسه شغال، الطلب التاني بيستنى نفس الـ Future بدل ما يخرج للشبكة | `InFlight` حوالين `CatalogRemoteSource.fetchWork` |
| ETag و304 | بصمة لنسخة الرد، والـ app بيبعتها في `If-None-Match`، فالسيرفر يرد 304 من غير body لو ماتغيرتش | `EtagInterceptor` على `GET /library` |
| Optimistic update | الشاشة بتتغير قبل رد السيرفر، ولو فشل بترجع ومعاها رسالة | مسح ملاحظة في `NotesCubit.remove` |
| Tolerant reader | الـ app بيقرا اللي محتاجه بس، ويتجاهل الحقول الجديدة، وdefault للناقص وfallback للـ enum الجديد | الـ DTOs بحقول nullable و`unknownEnumValue` |
| Additive change | تغيير في الـ API مابيكسرش النسخ القديمة: حقل أو endpoint جديد optional | إضافة `coverUrl` في `/v1/library` |
| State | البيانات اللي الشاشة بتترسم منها دلوقتي، والـ UI = f(state) | `LibraryLoaded(books)` |
| Ephemeral state | state بتخص widget واحدة ومحدش تاني محتاجها، فـ `setState` كفاية ليها | الباسورد ظاهر ولا مخفي في الـ login |
| Cubit | class بتمسك state واحدة وتطلّع نسخة جديدة منها بـ `emit` لما method تتنادى | `ReadingGoalCubit.increment()` |
| Bloc | زي الـ Cubit بس الـ input events، وكل نوع event ليه handler وسياسة concurrency | `CatalogSearchBloc` بيستقبل `SearchQueryChanged` |
| emit | بيطلّع state جديدة للـ stream، وبيتجاهلها لو `==` الحالية، وبيرمي `StateError` بعد `close` | `emit(state.copyWith(isRefreshing: true))` |
| Value Cubit | Cubit الـ state بتاعته قيمة واحدة (bool أو enum أو رقم) | `ViewModeCubit` بـ `LibraryViewMode` |
| Action Cubit | Cubit لعملية واحدة بتخلص: idle وinProgress وsuccess وfailure | `RemoveBooksCubit` بـ `ActionStatus` |
| One-shot effect | حاجة بتحصل مرة واحدة (SnackBar أو navigation) ومش جزء من اللي الشاشة بترسمه | `BlocListener` بـ `listenWhen` على `refreshFailure` |
| Event transformer | سياسة بتحدد الـ Bloc يعمل إيه لو event جه والقديم لسه شغال | `restartable()` للبحث و`droppable()` للصفحة الجاية |
| restartable | event جديد بيقفل الـ handler القديم، فالـ emit بتاعه مابيوصلش، بس الطلب نفسه مابيتلغيش | البحث في `CatalogSearchBloc` |
| droppable | أي event بيوصل والـ handler شغال بيترمي | `NextPageRequested` في الكتالوج |
| HydratedCubit | Cubit بيحفظ الـ state على الجهاز لوحده ويرجّعها لما الـ app يفتح | `CatalogFiltersCubit` بـ `storagePrefix` ثابت |
| ReplayCubit | Cubit فيه undo وredo للـ states | `NoteEditorCubit` بحد 50 خطوة |
| InheritedWidget | widget فوق الشجرة، وأي widget تحتها توصلها بالـ context وتتبني تاني لما تتغير. الأساس اللي provider وflutter_bloc مبنيين عليه | `BlocProvider` تحت الغطا `InheritedProvider` |
| ChangeNotifier | class في Flutter بتمسك state قابلة للتعديل وبتنادي `notifyListeners()` بإيدك بعد كل تغيير | `LibraryNotifier` في درس «أدوات Flutter وProvider» |
| provider | package بيوفّر objects للشجرة فوق InheritedWidget، بـ `context.watch` و`read` و`select` | `ChangeNotifierProvider(create: ...)` |
| Riverpod | state management وDI معًا: الـ providers متعرّفة برا الشجرة والـ state جوه `ProviderScope`، والـ lookup بيتأكد منه الـ compiler | `@riverpod class ReadingGoal extends _$ReadingGoal` |
| AsyncValue | الـ state بتاعة provider async في Riverpod: `AsyncData` أو `AsyncLoading` أو `AsyncError`، وممكن تشيل البيانات القديمة وهي بتعمل refresh | `switch` على `bookDetailsProvider(id)` في الـ UI |
| GetX | package بيجمع الـ state (`.obs` و`Obx`) والـ DI (`Get.put` و`Get.find`) والـ routing من غير context | `LibraryController extends GetxController` |
| MobX | state بـ `@observable` و`@action`، والـ `Observer` بيتتبع لوحده اللي اتقرا جواه | `ReadingGoalStore` بـ mobx_codegen |
| Reducer | في Redux: function نقية بتاخد الـ state والـ action وترجّع state جديدة | `readingGoalReducer` بيرجّع `GoalRules.up(goal)` مع `GoalIncreased()` |
| Signal | قيمة reactive صغيرة، وأي `computed` أو widget قرأها بيتحدث لوحده لما تتغير | `signal(20)` لهدف القراية |
| Strangler migration | نقل state management قديم شاشة شاشة، والجديد جنب القديم، لحد ما القديم يختفي | شاشة المكتبة من GetX لـ Cubit من غير ما الـ data layer تتلمس |
