<Level n="1" title="الفكرة بتشبيه">

<Analogy title="العناوين وبواب العمارة">

كل شاشة ليها عنوان زي عنوان الشقة: `/library` أو `/books/OL1`. والـ <b>redirect</b> هو بواب العمارة: قبل ما يدخّلك أي شقة بيسألك «انت مسجّل؟»، ولو لأ بيوديك لمكتب الاستقبال (صفحة الدخول). ولو انت مسجّل ورايح لمكتب الاستقبال تاني، بيقولك «انت جوه خلاص» ويطلّعك على شقتك.

</Analogy>


</Level>

| الـ method | بيعمل إيه |
| --- | --- |
| `context.go('/library')` | بيروح للعنوان ده وبيبني الـ stack من جديد حسب شجرة الـ routes |
| `context.push('/library/books/OL1')` | بيحط الشاشة فوق الحالية، وزرار الرجوع يرجّعك |
| `context.pop()` | بيرجع خطوة |

<Level n="3" title="الـ redirect مع الـ Cubit">

الـ redirect بيتنادى قبل أي تنقل. بس go_router مايعرفش إن حالة الـ auth اتغيرت لوحده، لازم تقوله عن طريق `refreshListenable`. والـ Cubit بيطلّع stream مش Listenable، فبنعمل كوبري صغير:

<CodeBlock label="redirect + refreshListenable">

```dart
class StreamListenable extends ChangeNotifier {
  StreamListenable(Stream<dynamic> stream) {
    _sub = stream.asBroadcastStream().listen((_) => notifyListeners());
  }
  late final StreamSubscription<dynamic> _sub;

  @override
  void dispose() {
    _sub.cancel();
    super.dispose();
  }
}

GoRouter buildRouter(AuthCubit auth) => GoRouter(
      refreshListenable: StreamListenable(auth.stream),
      redirect: (context, state) {
        final loggedIn = auth.state is Authenticated;
        final onLogin = state.matchedLocation == '/login';
        if (!loggedIn && !onLogin) return '/login';
        if (loggedIn && onLogin) return '/library';
        return null; // stay where you are
      },
      routes: [/* ... */],
    );
```

</CodeBlock>

<Diagram name="d-3549cdb506">

كل ما الـ AuthCubit يطلّع state جديدة، go_router بيعيد تشغيل الـ redirect ويقرر يوديك فين.

</Diagram>

دلوقتي لما الـ token يبوظ والـ AuthCubit يطلّع loggedOut (من الـ interceptor في درس dio والشبكة في الوحدة 3)، المستخدم بيتحول لصفحة الدخول من أي مكان في الـ app، من غير ما أي شاشة تكتب كود للموضوع ده.

وفي درس الـ Session في الوحدة 6، الـ AuthCubit هيزيد حالة تالتة، `AuthUnknown`، للحظة اللي الـ app لسه بيقرا فيها الـ token وهو بيفتح. والـ redirect هيوديها لـ splash، بدل ما يعرض صفحة الدخول لحظة وبعدين يحوّل للمكتبة.

### Deep links

لو حد فتح لينك `readly.app/library/books/OL1`، go_router بيبني الـ stack كامل: المكتبة تحت وصفحة الكتاب فوقها. والـ redirect بيتطبق برضه: لو مش مسجّل يروح للـ login الأول.

### StatefulShellRoute: كل تاب بحالته

Readly فيها 3 تابات تحت: المكتبة والكتالوج والإعدادات. لو كل تاب `GoRoute` عادي وبتنقل بينهم بـ `context.go('/catalog')`، المستخدم اللي كان نازل لنص المكتبة وراح الكتالوج ورجع، هيلاقي الليست من أولها، وspinner، وطلب جديد للسيرفر. ولو كان فاتح صفحة كتاب جوه المكتبة، راحت هي كمان.

السبب إن `go` بيبني الـ stack من شجرة الـ routes للعنوان الجديد بس. صفحة المكتبة مش جزء من `/catalog`، فبتتشال من الشجرة: الـ ListView بالـ scroll بتاعه بيتشال، والـ BlocProvider بيعمل close للـ LibraryCubit. ولما ترجع، كل حاجة بتتعمل من الأول.

الحل `StatefulShellRoute`: route بيلف التابات، وكل تاب جواه <b>branch</b> ليه Navigator بتاعه. والـ `indexedStack` بيحط الـ branches في `IndexedStack`، يعني widget بيعرض واحد بس منهم، والباقي بيفضلوا عايشين مستخبيين:

<CodeBlock label="التابات كـ branches">

```dart
GoRouter buildRouter(AuthCubit auth) => GoRouter(
      initialLocation: '/library',
      refreshListenable: StreamListenable(auth.stream),
      redirect: (context, state) {/* same as before */},
      routes: [
        GoRoute(path: '/login', builder: (_, __) => const LoginPage()), // outside the shell
        StatefulShellRoute.indexedStack(
          builder: (context, state, navigationShell) =>
              HomeShell(navigationShell: navigationShell),
          branches: [
            StatefulShellBranch(routes: [
              GoRoute(
                path: '/library',
                builder: (_, __) => BlocProvider(
                  create: (_) => getIt<LibraryCubit>()..load(),
                  child: const LibraryPage(),
                ),
                routes: [
                  GoRoute(
                    path: 'books/:id',
                    builder: (_, state) => BookPage(id: state.pathParameters['id']!),
                  ),
                ],
              ),
            ]),
            StatefulShellBranch(routes: [
              GoRoute(
                path: '/catalog',
                builder: (_, __) => BlocProvider(
                  create: (_) => getIt<CatalogSearchCubit>(),
                  child: const CatalogPage(),
                ),
              ),
            ]),
            StatefulShellBranch(routes: [
              GoRoute(path: '/settings', builder: (_, __) => const SettingsPage()),
            ]),
          ],
        ),
      ],
    );
```

</CodeBlock>

<CodeBlock label="الـ shell والتابات">

```dart
class HomeShell extends StatelessWidget {
  const HomeShell({super.key, required this.navigationShell});
  final StatefulNavigationShell navigationShell;

  @override
  Widget build(BuildContext context) => Scaffold(
        body: navigationShell, // the IndexedStack: hidden tabs stay alive
        bottomNavigationBar: NavigationBar(
          selectedIndex: navigationShell.currentIndex,
          onDestinationSelected: (index) => navigationShell.goBranch(
            index,
            // tapping the current tab again goes back to its first page
            initialLocation: index == navigationShell.currentIndex,
          ),
          destinations: const [
            NavigationDestination(icon: Icon(Icons.menu_book), label: 'Library'),
            NavigationDestination(icon: Icon(Icons.search), label: 'Catalog'),
            NavigationDestination(icon: Icon(Icons.settings), label: 'Settings'),
          ],
        ),
      );
}
```

</CodeBlock>

<Diagram name="d-shell-branches">

كل branch ليه Navigator والـ stack بتاعه. المكتبة ظاهرة وفوقها صفحة كتاب، والكتالوج مستخبي بس الـ scroll والـ Cubit بتوعه عايشين، والإعدادات لسه ماتبنتش لأن المستخدم مافتحهاش. والـ login بره الـ shell خالص.

</Diagram>

- <b>الـ goBranch بدل go:</b> بيرجّعك للـ branch بنفس الـ stack اللي سبته عليه. لو كنت فاتح صفحة كتاب في المكتبة ورحت الكتالوج ورجعت، هتلاقي صفحة الكتاب.
- <b>الـ scroll والـ Cubit بيفضلوا:</b> لأن الـ branch مابيتشالش من الشجرة، فالـ ListView والـ BlocProvider عايشين، والـ LibraryCubit مابيعملش close ولا `load()` تاني.
- <b>الـ branch بيتبني أول مرة تفتحه بس:</b> الإعدادات مش بتتعمل غير لما المستخدم يدوس عليها، وبعدها بتفضل عايشة.
- <b>الـ redirect لسه شغال:</b> بيتنادى مع كل تنقل، حتى `goBranch`. والـ `/login` بره الـ shell، فلما الـ AuthCubit يطلّع إن المستخدم خرج، الـ redirect بيوديه هناك والـ shell كله بيتشال بالـ Cubits اللي جواه. ولما يدخل تاني، التابات بتتبني من جديد.
- <b>الـ deep links:</b> `/library/books/OL1` بيفتح تاب المكتبة وفوقه صفحة الكتاب، والتابات التانية مستنية أول ضغطة.

كل تاب بقى ليه Navigator بتاعه وبيفضل عايش، فالرجوع ليه بيلاقيه زي ما سبته، والـ redirect لسه فوقهم كلهم.


</Level>

<Level n="4" title="تفاصيل بتفرق">

- <b>الـ redirect لازم يبقى سريع:</b> بيتنادى مع كل تنقل، فماتعملش فيه طلبات شبكة. اقرا الحالة من الـ Cubit وبس.
- <b>متى go ومتى push؟</b> go للتنقل لقسم رئيسي من أي مكان، وpush لما عايز المستخدم يرجع للي كان فيه (زي فتح تفاصيل كتاب). أما التابات اللي تحت، فبـ `navigationShell.goBranch` مع StatefulShellRoute، عشان كل تاب يحتفظ بحالته (آخر جزء في Level 3).
- <b>الـ routes بأنواع:</b> الـ `go_router_builder` بيخليك تكتب `BookRoute(id: 'OL1').go(context)` بدل string، فأي غلطة في الـ path تبقى compile error.
- <b>الـ router نفسه مايتبنيش جوه build:</b> لو اتعمل من جديد مع كل rebuild، الـ navigation state هيضيع.

<Note kind="interview" title="سؤال interview">

«إزاي تحوّل المستخدم لصفحة الدخول من أي مكان لما الـ session تنتهي؟» top-level redirect بيقرا حالة الـ AuthCubit، وrefreshListenable بيسمع على الـ stream بتاعه، فأي تغيير في الحالة بيعيد تشغيل الـ redirect تلقائيًا.

</Note>


</Level>

<Quiz>

<Question id="router-1">
<Ask>ليه محتاجين `refreshListenable`؟</Ask>
<Answer>

لأن go_router مش بيعرف إن حالة الـ auth اتغيرت لوحده. الـ refreshListenable بيقوله «اعيد تشغيل الـ redirect».

</Answer>
</Question>

<Question id="router-2">
<Ask>الـ redirect رجّع null. معناها إيه؟</Ask>
<Answer>

إن المستخدم يفضل في العنوان اللي رايحله، من غير تحويل.

</Answer>
</Question>

لأنه بيتنادى مع كل تنقل، فهيبطّأ كل حركة في الـ app.

</Answer>
