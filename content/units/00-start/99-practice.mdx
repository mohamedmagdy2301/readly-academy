### الـ checkpoint: ابني feature من غير الكورس

بعد ما تخلص، افتح مشروع فاضي وابني feature «قائمة منتجات» من أي public API في 3 ساعات من غير ما ترجع للفيديوهات. لو عدّيت كل النقط دي بثقة، انت جاهز للأسبوع 1:

<Tasks>
<Task id="p0-1">الـ domain مافيهوش ولا import لـ Flutter أو Dio أو json.</Task>
<Task id="p0-2">الـ Entity والـ Model منفصلين، والتحويل بينهم في مكان واحد واضح.</Task>
<Task id="p0-3">الـ repository contract في domain والـ implementation في data.</Task>
<Task id="p0-4">الـ use case بيرجع Either أو Result ومش بيرمي exception.</Task>
<Task id="p0-5">الـ Cubit مايعرفش حاجة عن الـ data layer خالص.</Task>
<Task id="p0-6">الـ DI متسجلة في مكان واحد (composition root).</Task>
<Task id="p0-7">كتبت unit test واحد على الأقل للـ use case بـ mock repository.</Task>
</Tasks>


<ReviewQuestion>هل محتاجين الـ Domain layer؟ اكتب رأيك في 3 سطور: امتى تشيله وامتى تسيبه، وإيه اللي وقف معاك في المحاضرات.</ReviewQuestion>
