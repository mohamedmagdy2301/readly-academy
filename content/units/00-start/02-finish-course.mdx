باقي من الكورس حوالي ساعتين (محاضرات 28 لحد 39). خلّصهم في أول 3 أو 4 أيام. مع كل محاضرة جاوب السؤال اللي قدامها، واللي ملقتلوش إجابة في الكورس هو بالظبط اللي هنغطيه في المراحل الجاية.

| المحاضرة | ركّز على | سؤال المراجعة |
| --- | --- | --- |
| 28. Models | العلاقة بين Model وEntity | الـ Model بيعمل extends للـ Entity ولا في mapper منفصل؟ وإيه عيب كل واحد؟ |
| 29. Data Source | مين بيرمي الـ Exceptions | الـ data source بيرجع Model ولا response خام؟ ومين مسؤول عن تحويل الـ error؟ |
| 30. Repository | تحويل Exception إلى Failure | لو عندك remote وlocal، مين بيقرر تقرا من فين؟ |
| 31. Presentation + DI | فين بيتعمل wiring للـ dependencies | الـ Cubit بياخد الـ use case في الـ constructor ولا بيجيبه من get_it جوه؟ |
| 32. DI (optional) | أنواع التسجيل | الفرق بين registerFactory وregisterLazySingleton، والـ Cubit يتسجل بأنهي واحدة وليه؟ |
| 33. Data Flow | اتجاه الـ dependencies مقابل اتجاه الـ data | ارسم بإيدك الـ flow من ضغطة زرار لحد ظهور النتيجة من غير ما تبص. |
| 34–37. Auth | التطبيق الكامل | الـ session بتتخزن فين؟ ولو الـ token انتهى في نص request هيحصل إيه؟ |
| 38. Domain? | النقد | اكتب رأيك في 3 سطور: امتى تشيل الـ domain وامتى تسيبه؟ (هنرجعله في الأسبوع 8) |
| 39. Compilation | الـ JIT والـ AOT والـ build modes | ليه الـ debug build أبطأ من الـ release، وإيه علاقة ده بالـ flavors؟ |
